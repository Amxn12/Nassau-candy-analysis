# Nassau Candy Sales Analysis

## Project Overview
This project analyzes the Nassau Candy Distributor sales dataset using Python. The objective is to clean the data, perform exploratory data analysis (EDA), and generate insights that can help improve business decisions.

## Objectives
- Clean and preprocess the dataset.
- Analyze sales and gross profit.
- Identify top-selling products.
- Analyze sales by state, region, and division.
- Create visualizations to present business insights.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## Dataset
The dataset contains information such as:
- Order ID
- Customer Name
- Product Name
- Sales
- Units
- Gross Profit
- Cost
- Region
- State/Province
- Division

## Project Steps
1. Imported the dataset.
2. Checked for missing values and duplicates.
3. Cleaned the dataset.
4. Performed exploratory data analysis (EDA).
5. Created charts for sales analysis.
6. Summarized key findings.

## Key Findings
- Calculated total sales and gross profit.
- Identified the top-selling products.
- Compared sales across regions and states.
- Visualized business performance using bar charts and other plots.

## Files Included
- `nassau_candy_analysis.ipynb` – Jupyter Notebook containing the analysis.
- `Nassau_Candy_Distributor_Cleaned.xlsx` – Cleaned dataset.
